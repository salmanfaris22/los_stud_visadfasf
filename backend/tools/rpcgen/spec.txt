# lms.v1 services. One line per RPC:
#   Name access [get] [stream] [rl=bucket/limit/window] | request fields | response | service call | summary
# access:   public | signed | student | staff | perm:module.action      get = no side effects
# fields:   id | page | name:uuid | name:uuid? (optional, "" = none) | name:uuids[min=1,max=500]
#           name:str[min=,max=,in=a/b] (! = required) | name:i32[gte=,lte=] | name:bool | name:ts | name:Type
# response: - | ok | ok="message" | okv (dto.OK) | strs | file | item:field:Type | items:Type | list:Type | custom{...}
# call:     Go expression; m is the request message. A leading Service.Method gets c.s. in front. custom = hand-written.
